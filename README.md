# Luka Džarić — portfolio

A one-page portfolio site: short bio, a packed image grid with hover labels, and a contact footer.
Plain HTML, CSS and JavaScript, no build step.

- `index.html` — the page and its text
- `css/style.css` — the look (colours, font, spacing)
- `js/projects.js` — **the only file to edit for the grid**: images, titles, categories, years
- `js/main.js` — builds and packs the grid (no need to edit)
- `images/` — your image files
